# Homebrew Tap for mohith-labs

Custom Homebrew tap for installing mohith-labs applications.

## How to Use

```bash
brew tap mohith-labs/tap
```

## Available Casks

### NetSpeed
Lightweight macOS menu bar app that displays real-time network upload and download speeds.

```bash
brew install --cask netspeed
```

**Features:**
- Compact stacked display (▲ upload / ▼ download)
- Color-coded arrows (green/blue)
- Adaptive KB/s → MB/s → GB/s formatting
- 2-second refresh interval
- Session totals and active interface info
- Launch at Login toggle
- ~1.7 MB, near-zero CPU, zero dependencies

**Requirements:** macOS 13.0 (Ventura) or later

**Uninstall:**
```bash
brew uninstall --cask netspeed
```
